notzine.com is my personal website built with Hugo, leveraging the PaperMod theme. It’s meant for sharing genuine content without any fluff.

## Key Features
- Static site generated by Hugo
- Clean, responsive design via PaperMod
- Pagination, reading time, and post navigation
- Configurable light/dark mode
- Supports multiple authors with customizable profiles
- SEO-friendly with robots.txt

## Quick Start

### Prerequisites
- Install Hugo (v0.112.4 or higher).

### Clone the repo
```bash
git clone https://github.com/justin-napolitano/notzine.com.git
cd notzine.com
```

### Run locally
```bash
hugo server -D
```

This starts a local server. Draft content is included by default.

### Build for production
```bash
hugo --minify
```

Site files will be in the `public` directory.

**Gotcha**: Comments are disabled by default. Enable them if you need a discussion feature.
